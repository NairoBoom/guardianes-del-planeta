# Guardianes del Planeta

Videojuego educativo sobre la separación de residuos en el colegio.
Proyecto STEAM grado 11 - Cristian López y Juan Noriega - I.E. Ángela María Torres Suárez.

Jugar: https://nairoboom.github.io/guardianes-del-planeta/

## De qué se trata

Es la semana ambiental y el colegio quedó lleno de basura mal separada. El jugador recoge los residuos del salón, la tienda escolar y la cancha, y los lleva a la caneca correcta del punto ecológico (blanca, verde o negra) antes de que se acabe el tiempo.

## Reglas

1. Se empieza con 0 puntos.
2. Residuo bien clasificado: +10 puntos.
3. Residuo mal clasificado: -5 puntos.
4. Hay 60 segundos para los 3 niveles (fácil, intermedio y difícil).
5. Se gana con 100 puntos.

## Archivos

- `index.html`: las pantallas del juego.
- `style.css`: los colores y el diseño.
- `js/game.js`: el código del juego (p5.js).
- `libreria/p5.min.js`: la librería p5.js.
- `assets/personajes/`: las caras de los personajes.
- `bitacora.md`: bitácora de programación y de IA.

Para jugar en el computador se abre `index.html` en el navegador.
