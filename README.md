# Guardianes del Planeta 🌎

Videojuego educativo 2D sobre reciclaje. Proyecto STEAM de grado 11, hecho por **Cristian López y Juan Noriega**.

**▶ Jugar:** https://nairoboom.github.io/guardianes-del-planeta/

El jugador elige su guardián (Cristian, Juan o Eco), recorre el parque, recoge los residuos y los deposita en la caneca correcta: papel, plástico u orgánicos.

## Reglas

1. Empiezas con 0 puntos.
2. Cada residuo bien clasificado vale +10 puntos.
3. Cada residuo mal clasificado resta 5 puntos.
4. Tienes 60 segundos para 3 niveles: fácil, intermedio y difícil.
5. Ganas si alcanzas 100 puntos antes de que termine el tiempo.

**Extras:** racha de aciertos, pregunta rápida entre niveles, récord guardado y personajes seleccionables.

## Estructura

| Archivo | Para qué sirve |
|---|---|
| `index.html` | Estructura de las pantallas |
| `style.css` | Colores, botones y diseño |
| `game.js` | Lógica del juego con p5.js (comentado y ordenado por secciones) |
| `libreria/p5.min.js` | p5.js 1.11.1, incluido para que funcione sin internet |
| `assets/personajes/` | Fotos y retratos de los personajes |
| `bitacora.md` | Bitácora de programación |

Para jugar en el computador basta con abrir `index.html` en Chrome, Edge o Firefox.
